Project: Offline Restaurant Management & POS Android/iOS Application

You are a senior React Native engineer responsible for building a complete offline-first Restaurant Management and Point of Sale (POS) application.

The application will be used primarily on Android tablets at a restaurant cashier point, but during development we will test using normal Android smartphones. The application must also support iOS devices.

The system must be:

Fast
Reliable
Fully offline
Touch friendly
Responsive to different screen sizes
Easy for restaurant staff to use
Maintainable and scalable

The application should be built using:

Expo React Native
TypeScript
Expo Router
SQLite local database
Zustand state management
React Native Paper UI components
Native device storage APIs
Bluetooth ESC/POS receipt printing
Business Context

This application is designed for a fast-food restaurant selling products such as:

Chips
Chicken
Beef
Burgers
Russian
Sadza
Rice
Soft drinks
Water
Juice
Other fast-food items

The restaurant operates in an environment where internet connectivity cannot always be guaranteed.

Therefore:

No cloud dependency
No online API dependency
All operations must work locally
All sales, inventory, users, and settings must be stored in SQLite

Future synchronization can be added later, but the first version must work completely offline.

IMPORTANT INVENTORY DESIGN

The system must support only TWO inventory tracking methods.

Do NOT add additional tracking methods.

Tracking Method 1: Recipe Based Products

Used for meals prepared by the restaurant.

Examples:

Chips
Sadza
Rice
Burgers
Chicken meals
Beef meals

The customer buys a product, but inventory is deducted from ingredients.

Example:

Product:

Chicken Burger

Price:
$5

Recipe:

Burger Bun       1 piece

Chicken Fillet   150 grams

Mayonnaise       20 ml

Tomato           2 slices

Lettuce          30 grams

When one burger is sold:

Reduce:

Burger Bun -1

Chicken Fillet -150g

Mayonnaise -20ml

Tomato -2 slices

Lettuce -30g
Tracking Method 2: Direct Stock Products

Used for items purchased and sold directly.

Examples:

Coca-Cola
Fanta
Water
Juice

Example:
